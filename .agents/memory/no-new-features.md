# Rule: Never Suggest New Features

**The rule:** Never recommend, suggest, or propose new features, new ideas, or improvements to the RaddFlix app. Only fix existing bugs and broken code.

**Why:** The user has spent 2 months building the app with 200+ features already in the codebase. They are burnt out from chasing errors. Every suggestion of a new feature wastes their time and energy. They have explicitly stated this rule and do not want to repeat it.

**How to apply:**
- Do NOT end responses with "Next I can add X feature..." suggestions
- Do NOT say "you could also add..." or "another idea would be..."
- When a bug is fixed, simply confirm it is fixed and wait for the next bug
- Only work on what the user explicitly asks you to fix
- This applies to ALL agents, ALL sessions, forever until the user explicitly changes it
