## Rule
Never use `\$` inside a Dart non-raw string when you want string interpolation.

**Why:** In Dart, `\$` is an escaped dollar sign — it produces a literal `$` character, NOT interpolation. The bug manifested because shell scripts generating Dart code escaped `$` to prevent shell variable substitution, but that escape was then stored verbatim in the Dart source. Pass 3 of the 3-pass episode filename match always compared record names against the literal string `s${em.group(1)!.padLeft(2,"0")}e...` instead of e.g. `s01e04`.

**Fix:** Use string concatenation `'s' + s + 'e' + e` to avoid any dollar-sign escaping ambiguity.

**How to apply:** Any time Dart source is generated by a shell script or Node.js template literal, audit ALL string interpolations — `\${}` in the Dart source is always a bug.

**Test:** `raddflix_flutter/test_suite/jazzdrive_logic_test.js` — 27 tests including Pass3 coverage. Run with `--live <shareUrl> [target]` on Jazz SIM device for full network test.
