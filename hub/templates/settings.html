JazzDrive Services

Pause services when they are not needed to avoid unnecessary requests to JazzDrive. JazzDrive rate-limits and blocks accounts that send too many requests.
Upload Service
Controls whether the background worker sends files to JazzDrive and sends keepalive heartbeats. Enable only when you need to upload — typically 1–2 times per day at most. Disable when not uploading to eliminate all JazzDrive traffic.
…
Scan Service
Controls whether the system scans JazzDrive accounts for new files. Scans are very infrequent — once a week, month, or even once a year is enough. Disable between scan runs to send zero requests to JazzDrive accounts.
…
Organizer Service
Controls whether the JazzDrive Organizer can run plan and auto-organize operations. Disable to prevent any organizer operations from touching JazzDrive accounts.
…

JazzDrive Network

Choose how JazzDrive requests leave the server. VPN / Direct sends all traffic through the WireGuard tunnel at OS level — no proxy code runs. Proxy routes requests through the HTTP/SOCKS proxy pool.
🔒
VPN / Direct
All JazzDrive IPs routed through wg0 WireGuard tunnel. Recommended — zero proxy overhead.
🌐
Proxy
Python proxy pool used for each JazzDrive request. Use only if the VPN tunnel is down.
