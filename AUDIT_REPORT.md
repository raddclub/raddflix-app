## Architecture Notes

### Position Save/Restore System
- **Active**: `_posTimer` (initState, every 10s) → `_saveWatchPos()` → key `wp_$fileId` → `_restoreWatchPos()` silently seeks on open
- **Removed dead code**: `_savePositionTimer` + `_saveCurrentPosition` + `_tryResumePosition` wrote to `resume_pos_$fileId` key that was never read

### Audio Filter Pipeline
All audio effects (EQ + Reverb + Lab + Balance) merge through `_buildMergedAfString()` → single `af=` MPV property. Never call `_np.setProperty('af',...)` directly — always go through `_applyAllAf()`.

### MPV Critical Rules
- Never `vf=` mid-play (hardware decoder conflict)
- Never `hwdec=` mid-play (use only when paused/stopped)
- Speed via `_np.setProperty` only, never `_player.rate`
- No local variable named `_np` (shadows state field)
- Always set `_videoOpened = true` BEFORE `_player.open()`

### JazzDrive Service
- 110-min TTL in-memory cache for stream links
- JSESSIONID must include full `.NODE` suffix for sticky load-balancer routing
- HTML response detection on both login + media endpoints
- 3-pass filename matching: exact substring → normalised → episode code (s01e04)

### DB Encryption
- SQLCipher AES-256 with Android Keystore device-bound key
- Migration chain: v1→v19 (titles, episodes, watch_positions, downloads, stream_cache, watchlist, cast, FTS5)
